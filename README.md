# Naomi-
Naomi es una plataforma de ciberseguridad e inteligencia artificial que protege cuentas, correos, regalías y activos digitales frente a phishing y robo de credenciales. Incluye Security Score, análisis de enlaces y recomendaciones automatizadas para creadores, empresas y profesionales que dependen de Internet para trabajar y crecer con seguridad.
